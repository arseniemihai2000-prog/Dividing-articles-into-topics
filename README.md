1. Dataset Loading: The 20 Newsgroups dataset was used, with three categories selected: alt.atheism, comp.graphics, and sci.space. A subset of 1000 documents was chosen for experimentation.
2. Text Preprocessing:
  -Punctuation, numbers, and special characters were removed.
  -Short words (less than 4 characters) were filtered out.
  -All text was converted to lowercase.
  -Stopwords were removed using the NLTK English stopword list. 
3. TF-IDF Representation: A TF-IDF matrix was constructed with a maximum of 500 features to reduce dimensionality and computation cost.
4. Latent Semantic Indexing (LSI): Truncated SVD with 5 components was applied to capture latent semantic structures in the data.
5. Topic Extraction: The top 10 terms for each of the 5 topics generated by LSI were displayed.
